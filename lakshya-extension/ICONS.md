# Icon Files Needed

The extension requires three icon files:
- `icon16.png` (16x16 pixels)
- `icon48.png` (48x48 pixels)
- `icon128.png` (128x128 pixels)

## Quick Solution

You can create these icons using:
1. **Online icon generators**: 
   - https://www.favicon-generator.org/
   - https://favicon.io/
   
2. **Design Tools**:
   - Canva
   - Figma
   - Photoshop

3. **Use the OpenSchema logo** or create a simple icon with:
   - The "⚡" lightning bolt symbol
   - Or "OS" text in a rounded square

## Temporary Workaround

If you don't have icons yet, you can:
1. Create simple colored squares using any image editor
2. Or comment out the icon references in `manifest.json` temporarily

The extension will still work, just without a custom icon in the Chrome toolbar.
