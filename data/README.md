# Data Directory

This directory contains reference data files used for:
- Learning relational priors (`--learn-relations`)
- Realism evaluation (`--evaluate-realism`)
- ML benchmarking (`--ml-benchmark`)
- Privacy simulation (`--simulate-privacy`)

## Example Files

- `ecommerce_transactions.csv` - Reference dataset for e-commerce fraud detection examples
- `ecommerce_v2.csv` - Alternative e-commerce dataset

Note: CSV files in this directory are gitignored.
